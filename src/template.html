Connections & data

Connect a Google Sheet through a small Apps Script web app. Sync replaces the “Reading log” sheet with your current local library.

1
In a new Google Sheet, open Extensions → Apps Script and paste this code.
2
In Apps Script Project Settings, add a script property named LITREADER_TOKEN with a private value.
3
Deploy as a web app with access set to Anyone, then paste the web app URL and matching token below.

Use a Zotero user library ID and API key. A read-only key can import; write access is needed to send an article and its notes.

◉The key is stored only in this browser’s local storage.

Your notes live in this browser. Download a JSON backup before moving the HTML file, clearing browser data, or switching browsers.
